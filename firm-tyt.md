# firm-tyt

## Коротко

firm-tyt — open-source firmware проект для TYT DMR радіо, що був натхненний і базувався на ідеях md380tools. Це важливий приклад того, як в коду кастомної firmware пішла зміна ідеології: замість vendor lock-in — відкритий, модульний, налаштовуваний код.

GitHub:
https://github.com/WD1CKS/firm-tyt

## Що робить цей тип firmware

Філософія тут стандартна для кustom DMR firmware:
- відкрити менюшки і конфіг
- зробити доступними вкладки key management і канальний список
- спростити створення локальних налаштувань
- забезпечити compatibility зі звичайним DMR stack і власними параметрами

## Як підходить до шифрування

У кастомних DMR прошивках шифрування зазвичай не “прибирається зовсім”. Замість цього робиться один із трьох варіантів:

1. Підтримка сторонніх ключів / локальних key tables
2. Розширення vendor key handling для додаткових алгоритмів
3. Переформатування UI та logic так, щоб key id / alg id / slot можна було зручно відслідковувати і міняти

Тобто, шифрування не зникає, а стає “прозорішим” і керованішим.

## Чим відрізняється від класичної прошивки

У заводському коді:
- будь-який key id обробляється всередині vendor firmware
- key import і валідація зашиті у locked menu або у CPS
- вам важко проникнути в crypto pipeline

У firm-tyt:
- є можливість глибше піти в код і логіку конфігів
- доступ до menu і параметрів дає інженеру розуміння, який key включений у який слот
- деякі проекти виводять частину key handling із vendor SDK в custom-managed layer

## Для декодера

Формально цей проект не є “абсолютно готовим декодером”. Він більше про:
- розуміння того, як кастомна прошивка модифікує DMR firmware
- що саме треба змінити, якщо хочеш додати локальний key store
- як працює management of algorithms, ID, keys і slots в DMR stack

## Загальний висновок

firm-tyt є гарним прикладом того, як кастомна прошивка формує “відкритий інженерний шар” над vendor firmware. Це важливо, якщо є мета зрозуміти, як DMR key flow і crypto flow працюють в реальних радіо — не в уявній теорії, а в готовій платформи, яку можна збирати і модифікувати.
