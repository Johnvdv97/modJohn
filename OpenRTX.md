# OpenRTX

## Коротко

OpenRTX — один із найважливіших open-source projectів для модифікації прошивок TYT/DMR радіостанцій. Він побудований як модульна прошивка для цифрових радіо і є важливим еталоном для того, як кастомний firmware підходить до DMR, key storage, лівого management і UI.

GitHub:
https://github.com/OpenRTX/OpenRTX

## Чому він важливий

У відміну від OEM-прошивки, OpenRTX не робить “чорний ящик” поверх радіо. Він робить декілька важливих речей:
- відкрита структура драйверів і модулів
- більш прозорий код для обробки радіопараметрів
- менш жорстка прив’язка до заводських меню
- можливість інтеграції кастомних алгоритмів і управління ключами

## Як він розвиває класичну модель прошивки

Класична заводська прошивка:
- закрита
- має жорстко зашиті блоби і UI
- key storage знаходиться в vendor-структурах
- функціональність шифрування тісно прив’язана до vendor SDK і flash layout

OpenRTX:
- розділяє основні компоненти: менюшки, FM/DMR logic, драйвери, flash, key management
- дає глибше розуміння того, де в радіо знаходяться крипто-структури і як їх можна змінювати
- по суті, це “framework” для того, щоб працювати не з закритим vendor кодом, а з відкритим стеком

## Як виглядає крипто-логіка в open-source радіо firmware

У кастомних прошивках звичайно немає “магічної” заміни DMR шифрування, а є кілька типових змін:

1. Зміна key storage
   - замість vendor-полів в codeplug або protected flash
   - custom key table або structured local storage

2. Зміна key selection flow
   - key id, alg id, colour code, slot або talkgroup можуть відображатися як окремі об’єкти

3. Модифікація DMR stack
   - пошук keystream і OFB / ARC4 / AES backend
   - коригування того, який масив ключів використовується на конкретному слоті

4. UI і menu patches
   - додані поля для key name, key value, key enable/disable

## Чим він відрізняється від класики

OpenRTX не “зламав” OEM шифрування автоматично. Він переосмислює всю модель радіо як відкритий інженерний пристрій:
- менше vendor lock-in
- краща видимість flash і key layout
- легше міксувати feature toggle і системи безпеки
- гнучкість для тестового / домашнього / local usage

## Що корисно для декодера

Якщо ви хочете робити свій цифровий декодер, OpenRTX дає важливі відповіді на питання:
- де держаться параметри для slot / TG / key id
- як кастомно зберігаються ключі
- де відбувається виклик crypto-подібного коду
- як build flow і flash layout взаємодіють з кодуванням

## Важливий висновок

OpenRTX не “відкриває” proprietary DMR crypto чудесним чином, але дає відкритий інженерний контекст, де crypto, config, flash, UI і runtime логіка зібрані в доступному вигляді. Це дуже корисно для дослідження, мікро-патчів і побудови власного інтерфейсу.

## Рекомендація

Для розробки декодера це один із найважливіших проектів, якщо ви хочете зрозуміти:
- модульну структуру кастомної прошивки
- як змінюють key flow в системі
- як працює графічний і кодплаг-патчінг у DMR радіо
