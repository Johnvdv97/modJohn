# radio_tool

## Коротко

radio_tool — це інструментальний проект, що не є “самою прошивкою”, а значною мірою набором утиліт для флешування, збірки і пакування кастомних DMR firmware. Для користувача він дуже корисний, бо дозволяє управляти ресурсами і збирати кастомний image, але сам по собі він не є “помічником для decryption” у сенсі crypto engine.

Website:
https://apexstrata.ie/work/radio-tool/

## Чому важливий

У контексті кастомних DMR firmware це важливо, бо:
- багато проектів вимагають правильний build pipeline
- radio tool допомагає формувати image і управляти firmware packets
- без цього важко застосовувати кастомні шифрувальні функції і flash-режими

## Чим відрізняється від прошивки

radio_tool — це скоріше інструментальний оркестр: зборка, прошивка, packaging, validation. Він не описує криптографію в коді як основний зміст. Його роль — зробити pipeline deployable і повторюваним.

## Для декодера

Від коду crypto він не дає безпосередньо глибокого insight. Але він важливий як частина вашого practical stack:
- збірка firmware image
- flash management
- тестовий запуск кастомних збірок
- допомога при розгортанні і розборі runtime config

## Висновок

radio_tool — не “crypto-спеціаліст”, а “технічний layer” між open-source firmware і реальним фізичним пристроєм. Ця роль важлива, бо без правильного flashing/packaging навіть дуже гарна crypto логіка ніколи не потрапить в радіо.
